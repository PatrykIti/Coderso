# What Is It

This playbook covers a practical commerce-first launch path for teams that need
products, collections, strong presentation, and supporting site structure.

# When To Use

Use it when the product catalog is the main destination and the surrounding site
exists to support product discovery and trust.

# Step By Step

1. Build product and collection structure first.
2. Connect supporting pages, templates, menus, and media.
3. Add supporting forms or trust surfaces only after the core catalog is clear.
4. Review preview, navigation, and commerce-supporting content before launch.

# Examples

- A boutique store launches with a single flagship collection first.
- A niche commerce site pairs a small catalog with editorial landing pages.

# Common Mistakes

- Designing the site before product and collection structure is clear.
- Treating media quality as a late-stage detail.
- Launching catalog pages without verifying navigation and support content.
