# What Is It

This playbook shows how to build a lead-generation-first site using pages,
forms, trust content, and supporting structured data where useful.

# When To Use

Use it when the primary outcome is qualified inquiry rather than direct booking
or commerce checkout.

# Step By Step

1. Build the core page journey first: offer, proof, and CTA.
2. Use Forms for capture and qualification.
3. Add Listings or structured records only if they help users compare offers or
   services.
4. Measure results through analytics and refine the weakest conversion step.

# Examples

- A workshop uses service pages plus a diagnostic inquiry form.
- A clinic uses practitioner pages plus a pre-qualification contact flow.
- A B2B service site runs campaign pages backed by structured case studies.

# Common Mistakes

- Adding too many modules before the primary conversion path is clear.
- Over-designing listings or booking when the actual need is qualified contact.
- Treating every page equally instead of optimizing the main conversion route.
