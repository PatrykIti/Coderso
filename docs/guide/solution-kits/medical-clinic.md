# What Is It

The Medical Clinic kit is a starter package for clinics that need practitioner,
service, and appointment-oriented workflows with a professional trust-focused
presentation.

# When To Use

Use this kit when the site needs structured practitioner data, service pages,
and clear patient action paths such as booking or pre-qualified inquiries.

# Step By Step

1. Apply the kit if practitioner discovery and appointment flow are central to
   the business.
2. Review practitioner, service, and booking-related structures.
3. Customize compliance-sensitive copy and local clinic details early.
4. Validate booking and contact flows before treating the site as launch-ready.

# Examples

- A multi-doctor clinic uses the kit to structure practitioners and services.
- A specialist practice uses it mainly for service discovery and contact rather
  than full online scheduling.

# Common Mistakes

- Launching with generic practitioner or service placeholders.
- Forgetting that trust, clarity, and contact instructions matter as much as
  the appointment flow itself.
- Treating all clinical workflows as identical when service setup differs.
