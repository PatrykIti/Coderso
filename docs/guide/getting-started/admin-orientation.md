# What Is It

Admin Orientation explains how the Coderso admin is organized before you start
changing content or configuration. The admin has two broad areas: core screens
such as Dashboard, Pages, Media, and Settings, plus Advanced modules for content
models, entries, widgets, forms, listings, booking, commerce, and solution kits.

# When To Use

Use this guide when you are new to the product, when you need to decide which
screen to open first, or when you are unsure whether a task belongs in core
site management or in Advanced workflows.

# Step By Step

1. Start on the Dashboard to check overall health, recent work, and security
   status.
2. Use Pages, Menus, Themes, and Settings for site-wide structure and behavior.
3. Use Advanced > Engine to model structured content and Entries to manage records.
4. Use Widgets, Forms, Listings, Booking, Commerce, Reviews, and Popups when
   you are building customer-facing product workflows.
5. Use Solution Kits when you want a guided, package-based starting point
   instead of building the structure manually.

# Examples

- A marketing team starts with Pages, Themes, Menus, and SEO before moving into
  Advanced forms for lead capture.
- A services business starts with Solution Kits, then customizes Booking,
  Listings, and Forms after the initial rollout.
- An editorial team relies mostly on Pages, Posts, Media, Menus, and SEO with
  only limited Advanced usage.

# Common Mistakes

- Opening Advanced modules before deciding whether the site really needs
  structured custom content.
- Treating Solution Kits as locked templates instead of editable starting
  points.
- Changing global settings too late, after teams have already created pages,
  forms, and routes with different assumptions.
