# What Is It

This playbook covers the manual path for businesses that do not match an
existing Solution Kit closely enough to justify a kit-first rollout.

# When To Use

Use it when the business model is unique, mixed, or still evolving and a
starter pack would create too much cleanup.

# Step By Step

1. Define the core outcomes first: content, leads, booking, commerce, or mixed
   workflows.
2. Model only the structured data you truly need in Engine.
3. Add presentation and workflow modules one layer at a time.
4. Use pages and templates to bridge the early experience while the data model
   matures.

# Examples

- A hybrid service-and-content business starts manually instead of forcing a kit
  fit.
- An internal operations site uses records and custom screens without a public
  kit-style presentation layer.

# Common Mistakes

- Forcing a near-match kit and spending more time undoing it later.
- Modeling too much too early without proving the workflow.
- Ignoring the need for playbook-style decisions just because the setup is
  manual.
