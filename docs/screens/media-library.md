# What Is It

Media Library is the central asset management screen for images and other
uploadable files used across pages, posts, widgets, forms, and launcher/avatar
surfaces.

# When To Use

Use Media Library when you need to upload new assets, inspect metadata, reuse
existing files, or confirm that an asset is safe to reference from multiple
screens.

# Step By Step

1. Upload or browse assets in the main library view.
2. Filter or search to narrow the list to a useful subset.
3. Open asset details to edit metadata such as title, alt text, or caption.
4. Reuse the asset from pages, widgets, themes, or assistant launcher/avatar
   settings rather than uploading duplicates.

# Examples

- An editor uploads campaign graphics and reuses them in pages and widget
  templates.
- A site owner stores a launcher avatar asset once and references it from
  assistant settings.
- A content team audits alt text before publishing a new landing page.

# Common Mistakes

- Uploading duplicates instead of reusing an existing asset.
- Ignoring metadata quality, especially alt text, before publishing.
- Treating Media Library like a file dump instead of a reusable asset catalog.
