# What Is It

SEO and Redirects are the control surfaces for search visibility, metadata
quality, and URL continuity across the site.

# When To Use

Use these screens when refining how content is discovered, when changing URLs,
or when protecting traffic and ranking signals during migrations and updates.

# Step By Step

1. Review SEO configuration and content-level metadata quality.
2. Add or validate redirects before changing or removing important routes.
3. Recheck public previews and navigation after redirect or SEO changes.
4. Use analytics and search behavior to decide which SEO or redirect updates
   matter most.

# Examples

- A marketing team updates page metadata before launching a campaign.
- A site restructure adds redirects so old links continue to work.
- A content team audits weak metadata after poor search performance.

# Common Mistakes

- Changing URLs without adding redirects.
- Treating SEO like copy polish instead of a structured publishing concern.
- Ignoring the connection between page changes, navigation, redirects, and
  discoverability.
