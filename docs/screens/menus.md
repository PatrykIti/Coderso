# What Is It

Menus is the navigation-management screen for building primary, footer, and
other menu structures used across the site.

# When To Use

Use Menus when pages, posts, or feature areas already exist and you need a
clear navigation path between them.

# Step By Step

1. Create or open the menu you want to manage.
2. Add links, reorder items, and build hierarchy where needed.
3. Match the menu structure to real user journeys instead of internal team
   jargon.
4. Revisit menus after major page, listing, booking, or commerce changes.

# Examples

- A brochure site uses a simple primary menu plus a footer menu.
- A service business keeps top-level navigation focused on booking, services,
  and contact flows.
- A commerce setup adds collection and support links after product structure is
  finalized.

# Common Mistakes

- Building navigation before the underlying page or route structure is stable.
- Overloading the primary menu with too many first-level destinations.
- Forgetting to update menus after adding a new kit-based or Coderso module
  workflow.
