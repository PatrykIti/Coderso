# What Is It

Admin Search is the fastest way to locate content, settings, or operational
surfaces when you do not want to navigate manually through the sidebar.

# When To Use

Use Search when you know the thing you need but not the exact screen, when you
are working across many modules, or when you need to jump to an item quickly.

# Step By Step

1. Open Search from the top search surface.
2. Search by content name, route, screen label, or relevant term.
3. Scan grouped results and open the matching item or screen.
4. Refine the query if the first result set is too broad.

# Examples

- A site owner searches for a page title instead of opening the Pages list and
  paging manually.
- A content architect searches for a content type or listing query by name.
- A new team member finds an unfamiliar settings page through search rather
  than memorizing navigation first.

# Common Mistakes

- Using overly broad queries and assuming the first result is the only valid
  destination.
- Expecting Search to replace understanding of content modeling and ownership.
- Searching for an item before it has a stable title, label, or identifier.
