# What Is It

Plugin Store is the extension-discovery and package-detail surface for browsing
available plugins and reviewing what an extension does before installation or
evaluation.

# When To Use

Use Plugin Store when the built-in product surfaces are not enough and you need
an extension, integration package, or marketplace-backed capability.

# Step By Step

1. Browse or filter the store catalog to find relevant extensions.
2. Open the plugin detail page to review scope, metadata, and fit.
3. Compare a plugin with built-in features before deciding to extend the
   system.
4. Validate permissions, operational impact, and ownership before rollout.

# Examples

- A team evaluates whether a custom integration should be a plugin instead of a
  manual process.
- An admin reviews plugin details before allowing installation in production.
- A product owner compares store options for a missing workflow capability.

# Common Mistakes

- Installing an extension before understanding the native product alternative.
- Treating the marketplace as a shortcut around governance or security review.
- Skipping package detail review because the plugin name sounds familiar.
