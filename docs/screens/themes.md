# What Is It

Themes is the site-wide presentation surface for controlling visual tokens,
theme profiles, and reusable presentation settings that affect multiple pages
and templates.

# When To Use

Use Themes when you want broad visual consistency across the site instead of
editing each page or widget separately.

# Step By Step

1. Review the active theme profile and base token values.
2. Adjust tokens, routes, or preview behavior where needed.
3. Validate global changes in preview before assuming page-level content is the
   issue.
4. Keep local page changes small when the real problem belongs to the global
   theme layer.

# Examples

- A rebrand updates color, spacing, and typography from Themes instead of
  editing dozens of pages individually.
- A launch team exports and reviews theme settings before promoting a design
  baseline.
- A site owner uses theme profiles to compare presentation variants safely.

# Common Mistakes

- Fixing a global theme issue inside one page instead of the theme layer.
- Changing tokens without checking dependent templates and previews.
- Treating theme configuration like page content rather than site-wide design
  infrastructure.
