# What Is It

These operational screens help you observe, verify, and protect the workspace:
Analytics for performance and content signals, Audit and Access Logs for
traceability, Backups for recovery, and Import/Export for controlled movement of
data or configuration.

# When To Use

Use these screens when you need evidence, operational visibility, or a safe way
to move or recover data.

# Step By Step

1. Check Analytics when evaluating content performance or usage trends.
2. Use Audit and Access Logs when investigating who changed what and when.
3. Use Backups before risky changes or when planning recovery readiness.
4. Use Import/Export for structured transfer workflows rather than ad-hoc
   database changes.

# Examples

- An admin checks Audit before rolling back a suspicious change.
- An operations lead creates a backup before a large content-model migration.
- A reporting owner uses Analytics to identify which pages or flows deserve
  refinement.

# Common Mistakes

- Waiting until after a risky change to think about backups.
- Using analytics as a replacement for auditability.
- Treating import/export like a shortcut around proper workflow ownership.
