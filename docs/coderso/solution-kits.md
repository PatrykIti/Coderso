# What Is It

Solution Kits are packaged starting points for common business shapes. They
combine content models, pages, forms, templates, and module recommendations into
one guided setup workflow.

# When To Use

Use Solution Kits when you want a strong starting point and a guided rollout
instead of building the full structure from zero.

# Step By Step

1. Choose the kit that matches the business model most closely.
2. Review the generated plan, modules, and actions before execution.
3. Execute the plan and review validation output.
4. Treat the kit as a baseline that you refine rather than a locked final site.

# Examples

- A workshop, clinic, salon, directory, or small e-commerce team starts from a
  matching kit and then customizes content and templates.
- A team uses a kit for setup speed but still replaces individual templates and
  workflows later.
- An admin compares the recommended kit with a custom manual build before
  committing.

# Common Mistakes

- Choosing a kit based on labels alone without checking the recommended modules.
- Expecting a kit to remove the need for later modeling, content, or UX work.
- Running the plan without reviewing which actions and resources are included.
