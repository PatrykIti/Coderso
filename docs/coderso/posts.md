# What Is It

Posts is the editorial workflow for article-style content. It combines list
management, authoring, revisions, preview, and publishing in a writing-oriented
experience.

# When To Use

Use Posts for blog content, editorial articles, announcements, or other content
that is better expressed as authored narrative rather than structured records.

# Step By Step

1. Start in the posts list to create or locate the article you need.
2. Open the post editor to write, structure, and format the content.
3. Review details, preview, status, and publishing controls before release.
4. Return to the list to manage lifecycle, filtering, and follow-up actions.

# Examples

- A marketing team publishes SEO-focused articles tied to campaign pages.
- A product team posts release notes and public updates.
- An editorial team manages long-form pieces without modeling them as Coderso
  records.

# Common Mistakes

- Using posts where a structured entry model would be easier to query and reuse.
- Publishing before previewing formatting and metadata.
- Treating the post list and editor as separate silos instead of one workflow.
