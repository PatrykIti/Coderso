# What Is It

Widgets and Template Editor are the reusable presentation surfaces for building
sections, templates, and composable UI blocks used by pages, custom screens,
and kit-driven starter assets.

# When To Use

Use these screens when content already exists but you need reusable structure,
layout, or template-level presentation rather than one-off page editing.

# Step By Step

1. Browse the Widget Library to find a suitable building block.
2. Create or edit templates when the same composition should be reused in
   multiple places.
3. Use template revisions and previews to review changes before wider rollout.
4. Return to pages, screens, or kits to consume the template where needed.

# Examples

- A landing page team reuses a hero, feature grid, and CTA structure across
  multiple pages.
- A custom screen uses screen-safe widgets for an internal workflow.
- A solution kit ships starter templates that the team later localizes or
  simplifies.

# Common Mistakes

- Confusing the widget library with page-level publishing.
- Editing many pages manually when a reusable template would reduce drift.
- Using a generic widget composition where a screen-safe or domain-specific
  template would be clearer.
