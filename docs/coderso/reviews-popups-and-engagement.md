# What Is It

Reviews and Popups are engagement surfaces for trust, conversion, and
attention-management workflows. Reviews focuses on moderation and social proof.
Popups focuses on timed or contextual overlays.

# When To Use

Use these screens when you want to increase trust, highlight key actions, or
control how users encounter prompts and social proof across the site.

# Step By Step

1. Decide whether the goal is trust-building, attention capture, or both.
2. Configure reviews moderation if user-submitted or workflow-managed reviews
   are part of the product.
3. Configure popups carefully so they support the main journey instead of
   interrupting it.
4. Revisit these screens after major campaign or conversion workflow changes.

# Examples

- A clinic highlights testimonials and reputation signals.
- A commerce launch uses popups for limited-time guidance or opt-in prompts.
- A directory site combines reviews with selective attention prompts for
  higher-intent users.

# Common Mistakes

- Adding popups before the core page journey is clear.
- Treating reviews as decoration instead of a moderated trust surface.
- Using aggressive engagement patterns that hurt the primary workflow.
