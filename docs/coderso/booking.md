# What Is It

Booking is the scheduling and reservation module for service-oriented sites. It
combines resources, services, availability, preview, and reservation management
into one operational surface.

# When To Use

Use Booking when appointments, time slots, or service reservations are part of
the product experience.

# Step By Step

1. Define services and the resources that can fulfill them.
2. Configure availability, blackout periods, and slot behavior.
3. Review the slot preview and reservation-facing experience.
4. Monitor reservations and adjust supply or timing rules as the workflow
   matures.

# Examples

- A clinic configures doctors, service duration, and availability windows.
- A beauty salon manages staff, services, and booking slot behavior.
- A workshop site uses Booking to handle appointment-style lead conversion.

# Common Mistakes

- Starting with slot tuning before the service and resource model is clear.
- Forgetting blackout rules or edge conditions before going live.
- Treating booking preview as optional instead of a required QA step.
