# What Is It

Forms is the builder for form structure and behavior, while Action Logs provides
execution visibility for downstream actions and automation tied to a form.

# When To Use

Use Forms when the site needs submissions, lead capture, qualification flows, or
workflow triggers. Use Action Logs when you need evidence of what happened after
form events were processed.

# Step By Step

1. Build the form structure and field behavior in Forms.
2. Configure the follow-up behavior expected after submission.
3. Publish or embed the form into pages, templates, or kit-based surfaces.
4. Inspect Action Logs when diagnosing automation issues or verifying outcomes.

# Examples

- A lead-generation page embeds a qualification form with follow-up actions.
- A booking-support workflow uses a richer intake form before scheduling.
- An operations team checks Action Logs after changing a form-driven automation.

# Common Mistakes

- Treating form structure and downstream actions as separate decisions.
- Embedding a form before confirming the post-submit workflow.
- Ignoring Action Logs when a submission seems to disappear after the UI step.
