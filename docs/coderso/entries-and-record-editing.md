# What Is It

Entries is the record-management screen for the content models you define in
Coderso Engine. It is where teams create, edit, and maintain structured data.

# When To Use

Use Entries when the data belongs to a modeled content type and should stay
consistent across records instead of being written freehand on a page.

# Step By Step

1. Open the relevant content type from Entries.
2. Create or edit records using the field structure defined in Engine.
3. Review metadata and validation before treating the record as ready.
4. Use related downstream screens such as Listings or Custom Screens when the
   record also needs a dedicated presentation or workflow layer.

# Examples

- A team edits practitioner, service, or location records for a booking site.
- A directory manager maintains provider records and taxonomy-aligned content.
- A commerce-support project tracks non-product supporting records in a
  structured way.

# Common Mistakes

- Using Entries for content that should still be a page or post.
- Ignoring field-level validation and then blaming downstream screens for bad
  display behavior.
- Forgetting that a record model often needs a presentation layer as well.
