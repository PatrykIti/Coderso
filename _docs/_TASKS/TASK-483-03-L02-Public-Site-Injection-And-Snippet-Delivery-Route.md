## Overview

- **Goal:** Inject the tracking snippet into every LIVE published-site document
  (never previews) so real visits reach the collector. The snippet is an inline
  IIFE appended before `</body>` with a fresh per-render nonce.
- **Owning module(s) to extend:**
  - `core/site/renderPublicPage.tsx` — `renderDocument()` (line 103) is the
    single document choke point used by all three exported page renderers
    (`renderPublicPageHtml` line 220 → renderDocument at 258,

    `renderPublicPageV2RuntimeHtml` line 339 → at 409). Add an explicit
    `analyticsScriptHtml?: string | null` field to `PublicPageRenderOptions`
    (line 22 — the Runtime and V2 option types derive from it) and a matching
    `renderDocument` parameter that appends the `<script>` before `</body>`.

    `preparedRuntime.needsListingRuntimeScript` (V2 pages that render a live

## Security Contract

- **Endpoint visibility:** the inline snippet is part of the public HTML. If a
  separate static asset is preferred, expose `GET /_analytics/a.js` (public,
  `Bun.file`-served, immutable cache headers); the nonce is then passed as a
  query param minted per page render, not baked into the cached file.
- **Auth model / RBAC / CSRF:** N/A (public read of a static script).
- **Rate-limit bucket:** `public_read` if a static route is added; the inline
  variant adds no new endpoint.
- **Validation schema-owner module:** N/A (no inbound payload here).
- **Anti-abuse controls:** the nonce embedded per render is generated by
  `createBeaconNonce()` (TASK-483-02-L01) at render time so each page issues a
  fresh, short-TTL token; never reuse a single global nonce.
- **Settings gate (owned by this leaf):** this leaf creates the global
  "analytics enabled" setting end-to-end. Key: `"analytics.trackingEnabled"`
  (boolean, default `true` — real analytics collect out of the box; DNT/GPC is
  still honored client- and server-side), added to `DEFAULT_SETTINGS` in
  `core/services/settings/settingsService.ts` (lines 48-83) so it consciously
  joins the reject-unknown allowlist (`ALLOWED_KEYS` line 89 /
  `resolveSettingKey` line 124 reject unknown keys). Accessor:
  `isAnalyticsTrackingEnabled()` in a new
  `core/services/analytics/trackingSettings.ts` that reads via `getSetting`.
  Ship a round-trip persistence test alongside the existing Bun-lane settings
  suite (`tests/unit/settings/settingsService.test.ts` pattern: `setSetting` →
  `getSetting` → restore/`deleteSetting`; the suite hits the SHARED remote test
  DB — touch only this key and restore it, never truncate). When the setting is
  `false`, do not inject the script at all.
- **Preview exclusion (mandatory):** never inject the snippet on preview
  renders. The render layer carries an `isPreview` flag
  (`core/site/renderPublicPage.tsx:28,113,154,208-215`) and
  `core/server/publicSite.tsx` renders admin previews through the same paths
  (`renderPageTemplatePreviewHtml` line 1028, the preview-token branch in
  `handlePublicRequest` around line 1553, and `renderDetailPagePreviewHtml`
  line 1398 → `renderPublicPageRuntimeHtml` at 1444 with `isPreview: true`).
  Build/thread the script only when `options?.preview !== true`, and have
  `renderDocument` skip emission when `isPreview` is set — otherwise admin
  preview traffic would pollute the analytics tables this task builds.
- **Secret/PII handling:** the snippet contains no secret.
- **CSP compatibility:** the codebase has NO per-render CSP nonce facility —
  CSP is a static admin-configured string
  (`core/services/settings/securitySettings.ts` `headers.csp: string | null`,
  line 69, default `null` at 175) applied verbatim by `applySecurityHeaders`
  (`core/server/middleware/securityHeaders.ts:19-21`). Document (in
  `_docs/SECURITY_SPEC.md`'s analytics section) that the inline IIFE requires
  `'unsafe-inline'` or a script hash in any custom `script-src`, and that the
  optional external-asset variant (`/_analytics/a.js`) is the preferred shape
  when an admin configures a strict CSP. Do not reference a document CSP
  nonce — none exists.

## Implementation Pseudocode

```ts
// core/site/renderPublicPage.tsx — renderDocument(..., analyticsScriptHtml?: string | null)
// (single choke point at line 103, reached from renderPublicPageHtml:220,
//  renderPublicPageRuntimeHtml:273 and renderPublicPageV2RuntimeHtml:339;
//  add `analyticsScriptHtml?: string | null` to PublicPageRenderOptions:22 and
//  forward it from all three renderers — do NOT reuse renderBodyScripts):
const analyticsHtml =
  analyticsScriptHtml && !isPreview
    ? `<script>${analyticsScriptHtml}</script>`
    : "";
// ...appended immediately before `</body>`, after bodyScriptsHtml.
// Mirror the same optional parameter on the local renderDocument (line 165)
// in core/site/renderPublicEntry.tsx so entry LIST pages are covered.

// core/server/publicSite.tsx — build once per LIVE render (preview !== true):
const analyticsEnabled = await isAnalyticsTrackingEnabled();   // this leaf's settings accessor (see Security Contract)
const trackingScript =
  analyticsEnabled && options?.preview !== true
    ? buildTrackingScript({ nonce: createBeaconNonce(), collectPath: ANALYTICS_BEACON_PATH })
    : null;
// Thread `analyticsScriptHtml: trackingScript` inside
// renderPublicPageHtmlInternal (line 861 — covers its callers at
// 992/1038/1553/1682/1731; the preview callers pass preview:true and get null),
// in renderEntryDetailHtml's renderPublicPageRuntimeHtml call (line 1339), and
// through renderEntryListHtml (line 1116) -> renderPublicEntryListHtml.

// Optional static delivery route inside handlePublicRequest (line 1467):
if (url.pathname === "/_analytics/a.js") {
  return new Response(Bun.file(ANALYTICS_SNIPPET_FILE), {
    headers: { "content-type": "text/javascript; charset=utf-8",
               "cache-control": "public, max-age=86400, immutable" },
  });
}
```

Data flow: each LIVE public render (V2 pages, legacy pages, homepage, entry
detail, entry list) mints a nonce, builds the script (L01), and injects it
before `</body>`; the browser runs it and beacons to the collector. When
tracking is disabled in settings, or the render is a preview, no script is
emitted.

Error handling: snippet build/inject failures must never break page rendering —
wrap in a guard that logs a warning and renders the page without analytics
(degrade gracefully, like the existing booking/script seams).
