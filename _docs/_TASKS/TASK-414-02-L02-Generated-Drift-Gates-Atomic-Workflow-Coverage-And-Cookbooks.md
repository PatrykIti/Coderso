## Generated Artifact Contract

`coderso-cms-capabilities-v1.json` is canonical UTF-8 JSON: schema
`coderso.cms-capabilities@v1`, two-space indentation, LF, one final newline,
stable key/array order, exact source digests, and no timestamps/absolute paths/
machine values. It contains product support states and safe identifiers, not
runtime payloads.

`--write` validates all sources and docs outputs in memory, serializes and
normalizes again for byte identity, stages bytes with a digest-bound journal
under `.tmp/cms-capabilities/output-transaction-v1/`, atomically replaces only
the final artifact, verifies final digest, then removes the journal. A leftover
journal returns `cms_capability_recovery_required`; it never guesses winner
bytes.

`--check` is strictly read-only for tracked and untracked filesystem state. It
compiles expected bytes and compares exact presence/digest. Only `--write` may
change the artifact, and no automatic runtime/startup write is allowed.

## Exact Parity Rules

The gate fails on any missing/orphan/duplicate/mismatch among:

- native feature/resource IDs and manifest records;
- exact native resource/schema/read/mutation owners, modalities, focused
  contract/test/cookbook evidence, and source-registry/exclusion closure;
- Admin route/control and permission catalogs;
- TASK-548 area IDs, composition relations, localized section bindings,
  required targets, corpus bundle, and coverage outputs;
- Agent support phase versus tool/action/schema/handler/policy/review/error/
  bounds/test descriptors;
- Designer stage/preview/promotion/generation-aware read adapters versus
  TASK-547 core package kinds and strict sidecars;
- route/rate/lifecycle/import contributions versus mounted registry;
- plugin contribution IDs/versions/permissions versus verified server adapters;
- supported states versus complete contracts, or unavailable states versus a
  closed machine-readable reason and negative test;
- checked-in generated bytes/source digests versus terminal source bytes; and
- developer cookbook steps/commands/owners versus the exact extension contract.

Adding, changing, deleting, or renaming a feature must fail until every joined
projection is synchronized. There is no warning mode, percentage threshold,
wildcard adapter, vague exclusion, or stale-artifact release path. Diagnostics
list bounded safe IDs/reason codes and a truncation count only.

## Implementation Pseudocode

```ts
export function compileCmsCapabilityManifestV1(input: {
  sources: CmsCapabilitySourceSetV1;
  docs: DocsCapabilityCompositionCatalogV1;
}): Result<CmsCapabilityManifestV1, CmsCapabilityParityReportV1> {
  const sources = normalizeAllRequiredCapabilitySources(input.sources);
  const docs = normalizeDocsCapabilityCompositionCatalogV1(input.docs);
  const manifest = normalizeCmsCapabilityManifestV1(
    projectCapabilityRows(sources, docs),
  );
  const findings = boundedSortFindings([
    ...diffNativeAdminAndManifest(sources, manifest),
    ...joinGuideAreaAtomicWorkflowSections(docs, sources, manifest),
    ...joinAgentContracts(sources, manifest),
    ...joinDesignerCoreSidecarsAndReadModels(sources, manifest),
    ...joinPermissionsRoutesRatesLifecycleAndExtensions(sources, manifest),
    ...verifyEvidenceAndCookbookOwners(sources, manifest),
  ]);
  return findings.length ? err({ pass: false, findings }) : ok(manifest);
}

export async function runCmsCapabilityCli(mode: "check" | "write") {
  assertNoUnresolvedOutputJournal();
  const manifest = unwrapOrReport(compileCmsCapabilityManifestV1(loadPureInputs()));
  const expected = serializeCanonicalCmsCapabilityManifestV1(manifest);
  assertCanonicalRoundTrip(expected);
  return mode === "check"
    ? compareTrackedBytesWithoutWrites(expected)
    : writeDigestBoundArtifactTransaction(expected);
}
```

**Data flow:** final Guide sources -> existing TASK-548 generators/checks ->
pure terminal native/Admin/Agent/Designer/extension descriptors + docs
composition catalog -> strict exhaustive joins -> canonical CMS artifact ->
required read-only release gate.

**Error handling:** use bounded `cms_capability_*` domain codes, including
`source_missing`, `source_invalid`, `guide_relation_drift`,
`agent_contract_drift`, `designer_adapter_drift`,
`generation_read_model_missing`, `extension_adapter_drift`,
`generated_stale`, `output_invalid`, and `recovery_required`. No source object,
docs body, private config, or user payload enters diagnostics.

**Regression-test shape:** deterministic bytes under shuffled inputs; strict
read-only check; interrupted output recovery; one-member mutation across every
join; legacy TASK-548 area-ID byte compatibility; atomic/workflow bidirectional
authorization; all generated TASK-548 outputs current; extension/new-feature
fixture failing until its full contribution/cookbook/docs set is complete;
independent backend-only resource, Admin control, Assistant action, Core/page
widget, Dashboard widget/data-source, package-kind, and plugin mutations each
failing until every required projection is complete.
