## Key Changes

### Dedicated Floating-Inspector Widgets (TASK-421)

- New pure adapter `core/services/pages/pageEditorControlUiModel.ts` maps every
  registry control to a presentational model (segmented / toggle / slider /
  slider+stepper / swatch / media / text; fail-closed unsupported model) and
  owns the segmented-upgrade threshold, bounded slider ranges from schema
  clamps, and the English option-label catalog.
- New `core/admin/ui/pages/editorControls/` primitives: SegmentedControl
  (horizontally scrollable, snap + arrow-key navigation), ToggleSwitch
  (`role="switch"`), SliderControl/SliderStepperControl with visible values,
  ColorSwatchControl (design-token swatches + picker + hex fallback + leading
  Transparent option writing `null` for nullable block colors),
  MediaPickerControl wrapping the shared MediaPicker.
- All section and block panels route through the adapter: zero native selects
  and zero native number-arrow fields remain for upgraded kinds (verified live
  with the audit-style classifier on hero and button: switch/swatch/range/
  segmented counts > 0 in every panel); free-form text (copy, alt, href,
  anchor) deliberately stays text.
- Block visual styles (background/textColor/border/radius/shadow/opacity) now
  land on the block's visual element (button anchor, image element) instead of
  the wrapper frame; the frame keeps layout-only style. Owner-reported drift.
- Tooltips are metadata-driven on all toolbar category/action buttons;
  one-panel-at-a-time behavior; viewport-safe panel scroll. The Responsive tab
  stays a shell + breakpoint readout (content owned by TASK-425).

### Inline Canvas Text Editing (TASK-422)

- New Bun-free `core/services/pages/pageInlineEditContract.ts`: inline-editable
  target map (heading/text/quote/statistic/button label/list items), sanitize
  and commit helpers with the empty-commit policy; 31 Vitest tests.
- Shared renderer exposes an inline-text hook wrapping the exact painted text
  node (identity fallback keeps the public front byte-identical); the canvas
  renders fail-closed contenteditable regions: dblclick/Enter edits, Escape/
  blur commits through the same device-scoped update path the panel uses,
  editor hotkeys are suppressed while editing.

### Responsive Delivery On The Public Front (TASK-423)

- New deterministic `core/services/pages/pageResponsiveCss.ts` builds scoped
  `@media` rules from section/block responsive overrides (schema-clamped
  values only, id escaping, diagnostics for non-expressible deltas) and
  exports the renderer scope-attribute constants.
- `publicSite` emits the responsive CSS for real visitors over the unflattened
  document while keeping desktop-resolved base markup; explicit
  `previewDevice` keeps the flattened preview semantics; emission failures
  degrade to desktop-only with a warning.
- Live verification: tablet 640 / mobile 360 overrides compute max-width 360px
  at a 390px viewport, 640px at 800px, 1080px at desktop.
