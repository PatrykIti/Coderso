## Key Changes

### Per-Block Typography (TASK-424)

- `PageBlockStyleV2` gains five nullable token-backed fields (fontFamily
  sans|display, fontSize sm..5xl, fontWeight, lineHeight 1-2.5, letterSpacing
  -2..8px) with strict-write/lenient-read normalizers and JSON-schema parity;
  unset/null keeps the baked classes, so legacy documents render byte-identical.
- The renderer paints typography on the same node for canvas and front;
  responsive override slots flow through `pageResponsiveCss` `@media` emission.
- A per-block Typography panel (text-capable blocks only — no consolidated
  section-text surface) renders dedicated widgets via the shared adapter.
- Post-smoke fixes: clicking an inherited segmented value at tablet/mobile now
  pins a breakpoint override (`commitActiveOption`); `props.align` overrides
  for heading/text emit a scoped `text-align` rule on the text node; font-size
  scale extended to 3xl/4xl/5xl owned by `DesignTokens.typography`
  (`--text-3xl..5xl` emitted by `tokenCss`); the editor canvas re-paints the
  site typography variables so WYSIWYG matches the front instead of the admin
  theme scale.

### Responsive Tab Content (TASK-425)

- The Responsive tab now owns real content: hide-on-desktop/tablet/mobile
  switches over the existing `visibility.visible` override paths, an explicit
  per-field override list with reset-inheritance actions, and the new section
  `layout.stackVertical` boolean (full 4-layer chain + `@media` rule) that
  forces a single column beating the template-floored count.
- The device switcher shows labels with px readouts (Desktop 1080 / Tablet 744
  / Mobile 390) plus an editing-scope pill.

### Preview Surface And Toolbar Shell (TASK-451)

- Preview root cause diagnosed (the `/preview` route was never missing):
  Bun `fetch` resolves `*.localhost` to IPv6 only while the dev server binds
  IPv4, so the server-side probe failed and the dialog refused to mount the
  iframe. `fetchPreviewProbe` now retries loopback names once against
  `127.0.0.1` with the original Host header; the token security model is
  unchanged. The dialog renders the saved draft (draft-vs-published proven
  live).
- `resolveToolbarTargetLabel` is the single owner of floating-toolbar labels:
  type display names only ("Text tools", "Statistic tools"), user content no
  longer leaks into aria labels. Adopter verification stays with
  TASK-438/446/447.
- Per-gap inline "Add section" zones insert at the exact gap index through the
  existing command palette; the top button remains.

### Page Templates Surface Rewrite (TASK-420)

- New Page-v2-native template library: `pageTemplateLibrarySchema` (strict,
  reject-unknown, machine-readable `PageTemplateError`),
  `pageTemplateLibraryService`, `pageTemplates` table (migration
  `0058_exotic_shaman.sql` + snapshot + journal), a 7-route internal admin
  family with `mapPageTemplateError` and registration tests, `page-template`
  preview target on the public Page v2 pipeline (fail-closed; the legacy
  `widget-template` target is deliberately unresolvable), the full admin cache
  contract (`pageTemplates:*` keys, cached client, cacheBus, prefetch), and an
  admin list + editor reusing the shared Page Editor v2 shell. The obsolete
  Advanced Widgets/widget-template surface (routes, clients, UI, nav, cache
  keys, assistant hydration) was deleted; frozen storage/preview/replacement
  contract lives in `_docs/PAGE_MODEL.md`.
