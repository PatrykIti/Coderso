## Key Changes

### Pages Editor Data-Loss Fix (TASK-449 / TASK-442)

- Live captured-payload reproduction (coderso-dev-core-host + playwright-cli,
  .env admin credentials) proved the audited columns-specific save drop and
  the empty-list prune are **not reproducible at HEAD** on the clean editor
  path: autosave/save/publish payloads, stored `currentData`, reopen, and the
  published front all keep both blocks, and pages source is byte-identical to
  the audited tree.
- The reproduction instead captured a real **block-agnostic** data-loss path:
  a stale/empty cached `pages:detail` record plus a `pageDetail` cacheBus
  broadcast replaced the live editor document through the rehydration effect
  (`PageEditor.tsx:1520-1532`, guarded only by `hasUnsavedChanges`), reaching
  the audit's exact end state (editor `s=0/b=0`, published empty front).
- Fix: the rehydration now applies a cached record only when it is strictly
  newer (`updatedAt`) than the loaded page (`isNewerPageDetailTimestamp`);
  unparsable timestamps fail closed, the dirty-state guard is unchanged, and
  legitimate newer-record background rehydration is preserved.
- Regression coverage: stale/equal/unparsable broadcast scenarios in
  `tests/vitest/ui/page-editor-v2-flow.test.tsx`, plus a new schema-layer
  guard suite `tests/vitest/pages/page-document-v2-block-roundtrip.test.ts`
  (21 tests: every editor-insertable block type round-trips write/read/publish
  with default props; columns empty-slot/nested-children/overflow pins; list
  empty/coercion/populated pins).
- Live post-fix verification: dropper injection no longer wipes the document
  (older/equal/unparsable variants), newer-record rehydration still applies,
  and columns + default-empty list survive Save -> reload -> Publish -> front
  end to end. Evidence: `.tmp/phase0/columns-repro.md`,
  `.tmp/phase0/list-repro.md`, `.tmp/phase0/postfix-verify.md`.
- Follow-up split per AGENTS.md: **TASK-454** (autosave revisions are never
  promoted to `currentData`, no SPA unsaved-changes navigation guard, mount
  path trusts a TTL-fresh poisoned cache without revalidation).
- TASK-449-03 (closure sweep) stays open, blocked on TASK-421/TASK-423;
  TASK-442-01-L01 surface adoption stays open, gated on TASK-421/TASK-422.
