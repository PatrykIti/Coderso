## Access-Type Guidance

- `open-source`: source repository or MIT/Apache-compatible component library;
  still verify license before copying code.
- `docs-example`: product documentation or API/component examples; summarize by
  default.
- `premium-reference`: paid catalog or preview. Use only observations and
  screenshots allowed by terms; do not copy source.
