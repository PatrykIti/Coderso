# Footer Decision Matrix

| Researched option | Sources | Decision | Coderso editor/schema implication |
|---|---|---|---|
| Multi-column link groups | Flowbite React, daisyUI, Tailwind UI Plus | Keep | Visual `Columns` section owns grouped links and headings. |
| Source menus/policies | WordPress, Shopify | Keep | Allow menu/policy sources plus safe manual links. |
| Logo/brand/copyright/social | Flowbite, HyperUI | Keep | Visual `Brand` and `Legal` sections own brand text, copyright, social links. |
| Newsletter slot | Flowbite, Tailwind UI Plus, Mailchimp | Adapt | Footer can reference newsletter settings; public-write security remains backend-owned. |
| Dense ecommerce locale/currency controls | Flowbite, Shopify | Adapt | Future commerce-specific option; do not add unless source exists. |
| Raw provider signup code | Mailchimp examples | Reject | Store safe integration references only; no copied embed/script code. |
