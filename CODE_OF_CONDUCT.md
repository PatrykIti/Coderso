# Code of Conduct

Coderso is built with kindness, curiosity, and respect.

The goal of this project is to create useful software that helps people build,
publish, and extend websites and digital products. A healthy community matters as
much as the code itself.

We want Coderso to be a place where people can ask questions, share ideas,
contribute improvements, and learn without fear of being mocked, dismissed, or
treated unfairly.

## Our Standards

Participants are expected to:

- Communicate clearly, respectfully, and with good intent.
- Be kind to people with different backgrounds, skill levels, and communication
  styles.
- Focus feedback on ideas, code, behavior, and product outcomes.
- Give constructive criticism in a way that helps the project move forward.
- Accept feedback with patience and technical substance.
- Assume that maintainers and contributors may be working with incomplete
  context.
- Help keep public discussions safe, useful, and welcoming.

Good contributions are not only code. Helpful bug reports, thoughtful questions,
documentation fixes, design feedback, testing, and encouragement all matter.

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment, threats, intimidation, or sustained disruption.
- Personal attacks, insults, trolling, or discriminatory language.
- Public or private abuse toward contributors, maintainers, users, or reporters.
- Publishing private information without permission.
- Sharing secrets, credentials, customer data, or private security details in
  public channels.
- Repeatedly ignoring maintainer direction on scope, security, or conduct.
- Using the project spaces to shame, pressure, or manipulate others.

## Scope

This code of conduct applies in all Coderso project spaces, including:

- repository issues,
- pull requests,
- discussions,
- review comments,
- community channels,
- project-related events,
- private maintainer interactions related to the project.

## Reporting

If you experience or observe behavior that violates this code of conduct, report
it privately to the maintainers through the repository owner or a maintainer
channel.

Do not use public issues for sensitive personal, conduct-related, or
security-related reports.

When reporting, include as much context as you safely can:

- what happened,
- where it happened,
- who was involved,
- links or screenshots if appropriate,
- whether immediate action is needed.

## Enforcement

Maintainers may remove content, edit or close discussions, limit participation,
block accounts, or take other reasonable action to protect the project and
community.

Enforcement decisions should be proportional to the behavior, its impact, and
the available context.

The goal is not punishment. The goal is to keep Coderso safe, useful, and
respectful for everyone who wants to participate in good faith.

## Project Values

Coderso is guided by a simple idea:

> Build helpful things, treat people well, and leave the project better than you
> found it.

Kindness, compassion, patience, and practical help are welcome here.
